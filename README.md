# GitHub Learning Log

A small website that teaches GitHub through ten hands-on missions. I built it to learn Git and GitHub as a beginner.

**Live site:** https://sachi-ask.github.io/Hello/

## What it does

- Shows ten missions, each one a real GitHub skill
- Tracks my progress with a progress bar
- Keeps a journal of what I learned

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure |
| `style.css` | Colors and layout |
| `script.js` | Missions and progress tracking |
| `entries.js` | My learning journal |

## What I learned

- Committing changes with clear messages
- Publishing a site with GitHub Pages
- Creating branches and opening pull requests
- Merging, opening issues, and forking a repo

## Built with

Plain HTML, CSS and JavaScript.
